## Зафиксированный результат

Канонический результат — `codex/ml-final`, итоговый коммит `f6a5820`; протокол зафиксирован ранее в `0640727`. Данные — UCI Online Retail II, CC BY 4.0: 737 календарных дней, 333 обучающие даты. [Паспорт](../data/processed/manifest.json) · [Протокол](../experiments/final_protocol.md) · [Итоги test](../artifacts/final_results.md).

На test loss смеси **£2,455.68**, постоянного правила **£2,483.98**, прошлой недели **£4,950.14**. Основная разница — loss смеси минус loss постоянного train-Q80: **−£28.30**, парный 95% интервал **[−£484.27; +£707.08]**. Он включает ноль: преимущество над сильным правилом не установлено. Смесь уменьшает средний дефицит, увеличивая средний неиспользованный резерв. Стоимость 4:1 — допущение сценария, не фактическая денежная выгода.

После обновления Git обнаружены **два параллельных test-запуска**: `codex/ml-final` и `glm5.3flash/Demo`. Их test CSV совпадают; небольшое отличие intercept в JSON около 3×10⁻¹² — численная погрешность. Для подачи используем протокол, артефакты и аудит ML-владельца; параллельную переработку кода не смешиваем. Исторический протокол сохраняем. Нельзя утверждать, что команда запускала test только один раз, или запускать новый подбор по уже раскрытым исходам.
