# Codex 1 · подготовить демо к записи

Модель в Codex — **GPT-6.1-Sol** (`gpt-6.1-sol`).

Уровень рассуждения — **Medium** (`medium`).

ReserveWeek, устройство 1. Подготовь версию демо для записи двухминутного англоязычного видео. Первый экран уже реализован в demo/app.py и demo/index.html. Сохрани его, быстрый выбор 2011-04-04 и 2011-01-18 и возможность раскрывать фактическую сумму кнопкой.

Репозиторий https://github.com/ionnixf/Veritas.git. Проверь `git status` и выполни `git fetch origin`. Создай рабочую ветку `codex/demo-release` от `origin/codex/team-start`. Если эта рабочая ветка уже существует, продолжи её и включи актуальную общую ветку. Сохрани текущие незакоммиченные изменения при переключении. Демо и ML уже объединены в `codex/team-start`. Твои изменения относятся к `demo/`, ML выполняется параллельно на втором компьютере.

Отметь на экране исторический период примеров (validation) и объясни простыми английскими словами, что означает постоянный резерв. Добавь короткую подпись о том, что данные отражают зарегистрированные отмены заказов. Визуально и на слух должно быть понятно, чем нехватка средств отличается от неиспользованного остатка. Проверь уже готовый экран прежде, чем менять его.

Открой оба сценария в браузере, проверь сброс раскрытого результата, читаемость сумм в записи 1280×720 и запуск одной командой без сети. Источник сумм — CSV, имена и значения существующих полей сохраняются. Для 18 января ожидаются £24,050.42 резерва, £81,851.42 отмен и £57,801.00 нехватки. Подготовь третьему участнику три действия для самостоятельного прохождения и объяснения сумм. Его отзыв можно включить, когда он поступит.

Обнови `demo/README.md` короткой инструкцией для записи. Сделай коммит, отправь рабочую ветку в GitHub и открой PR с base `codex/team-start`. Верни ссылку, команду запуска и порядок действий для оператора. Для записи демонстрации достаточно validation. Владелец финального запуска и таблицы результатов на test — участник 2.
